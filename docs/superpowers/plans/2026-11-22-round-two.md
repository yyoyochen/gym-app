# Round Two Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace native selects and date inputs with in-style sheets, align numbers, add step sparklines and a best-weight-at-reps table, quiet the lift chart, and clean up settings and controls.

**Architecture:** Pure models (calendar, sparkline, rep maxes, marker geometry, storage note, set-kind rules) carry the logic and the unit tests; kit components (`Select`, `DatePicker` sheet, `InfoButton`, `Sparkline`, `Load`) only paint them. Removals (set kind picker, powerlifter comparison, System theme) are done last so each earlier commit stays green.

**Tech Stack:** React 18, TypeScript, Vite, Vitest (`npm test` from the repo root), hand-drawn SVG, plain token CSS.

**Spec:** `docs/superpowers/specs/2026-11-22-round-two-design.md` (approved 2026-11-22). Mockup (outside the repo): `gymbro/mockups/round-two-ideas.html`.

All paths are relative to the repo root; source files are under `web/src/`. Branch `round-two`.

## Global Constraints

- Local only: never `git push`, never open a PR, never merge to `main`.
- Commit messages: no `Co-Authored-By`, no `Claude-Session`, no "Generated with" line, no names of private local files. After each commit run `git log --format=%B -1` and confirm none appear. Never bypass the pre-commit private-data hook.
- Styles use tokens only. `node tools/check-styles.mjs web/src` stays at **0 violations**, `ds-allow` count at most **6** (5 today; Task 7 removes one). No new colours, no new type roles (`micro`, 10 px, is the smallest label). The `dot` rule applies: no middle-dot separators.
- Touch targets at least 48 px (`--touch-min`); the (i) button gets a 48 px hit area the way `.toggle::after` does.
- Never commit screenshots, mockups or real training numbers. Test data in unit tests is synthetic.
- `profile.benchmarkPopulation` stays in the data model and backups (old backups must restore); only the UI and code that uses it go.
- Verification: unit `npm test`, types `npm run typecheck`, full gate `npm run build`. Browser checks use the private preview: `~/.gymbro-preview/build-s1.sh`, open http://localhost:5193 (the `gymbro-s1` preview), unregister the service worker and clear caches before each reload, seed with `import('./__private__/seed.js')` if the app shows onboarding. Preview data may contain leftover test sessions from earlier work.
- Exact values: sparkline 72 × 22 px, 1.5 px ink stroke, accent 5 px end square, last 12 sessions; rep counts `[1, 2, 3, 5, 8, 10, 12]`; session name max 40 characters; calendar Monday first, six-week grid.
