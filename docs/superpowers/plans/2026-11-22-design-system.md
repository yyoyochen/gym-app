# Design System (roles, scale, style check) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every text style, spacing value and line in GymBro comes from a
named token. A bundled glyph font draws `░▒▓█`. A style check fails the build
and the tests on any drift.

**Architecture:**
- Tokens and role classes live in `tokens.css` and a new `type.css`.
- A Node check (`tools/check-styles.mjs`) scans CSS and TSX inline styles
  with per-declaration regexes. It runs in `npm run build`, and as a vitest
  test.
- A Python fontTools generator writes the 4-glyph `gymbro-glyph.woff2`.
- Screens migrate file by file onto the tokens. Two small kit components take
  the repeated row and legend patterns.

**Tech Stack:**
- React 18
- TypeScript
- Vite
- vitest
- plain CSS
- Node ESM tools
- Python 3 + fontTools 4.68, already installed

**Spec:** `docs/superpowers/specs/2026-11-22-design-system-design.md` (approved
2026-11-22, commit e8174dd).

## Global Constraints

- Work on a new local branch `design-system`, cut from `tab-jobs` HEAD. No
  push, no merge, until the owner says so.
- Commit messages carry no Claude attribution. No `Co-Authored-By`, no
  `Claude-Session`. Check with `git log --format=%B -1`.
- Colours don't change. Dark ink stays `#fef8ec` (cream), and no new colour
  appears.
- Out of scope: motion, navigation, icons, the dither shadows and screen
  layout. Only sizes, spacing and lines move.
- `web/src/styles/dither.css` is generated by `tools/dither/build-css.mjs`.
  Edit the generator, never the output.
- No new npm dependencies.
- Fonts stay bundled and must appear in the service-worker precache.
- Old type tokens are renamed or deleted, with no aliases.
- Escape hatch: a same-line `/* ds-allow: <reason> */` in CSS, or
  `// ds-allow: <reason>` / `{/* ds-allow: <reason> */}` in TSX.
- Screenshots and real data stay outside the repo, in
  `~/.gymbro-preview/ds-before/` and `ds-after/`.

## Review Focus

1. **Glyph font offline.** On a cold offline start, dither bars must still
   draw in GymBro Glyph, which means the woff2 must be precached. Task 3 adds
   a `check-bundle` assertion.
2. **Narrow phones.** At 320 px wide, the fixed 56 px `num-xl` (it was fluid
   52–72 on onboarding) and the 40 px `title-lg` must not cause a horizontal
   scroll. Task 7 checks this in the browser at 320 × 568.
3. **Keyboard focus.** Rule 4 now covers `outline`. Focus rings must stay
   visible after their widths move to `--rule-w`. Task 5 tabs through Today
   and Setup in the browser.
4. **Escape-hatch creep.** If `ds-allow` grows, drift returns. Task 5's
   baseline test caps allowed lines at 6, and each must have a non-empty
   reason.
5. **Light theme.** Size and line merges must hold on salmon paper too.
   Captures in Task 2 (before) and Task 7 (after) cover both themes.
