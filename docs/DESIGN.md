# GymBro design system: "Ink & Dither"

*Approved 2026-11-21. Replaces LUME (mint on petrol dark), which is retired: no
LUME colour, radius or shadow should appear in new work. Tokens:
`web/src/styles/tokens.css`. Components: `web/src/ui/kit/` (import from
`ui/kit`). A live gallery of every component is at `#/kit` in preview builds.*

## 1. Principles

1. **One ink.** Each theme is one paper, one ink and one accent. No other
   colours anywhere, including errors.
2. **The number is the hero.** Every screen leads with one big heavy number
   (Schibsted Grotesk 800, tight tracking). Everything else is quieter.
3. **Weather-app hierarchy.** A small grey label sits over a bold value. No
   cards, no boxes around content, no shadows, no rounded corners; sections are
   separated by space and a dotted rule.
4. **Spec labels are the voice.** Space Mono uppercase for labels, lockups and
   notes: `[SESSION A]`, `//NOTE`, `©21.11.26`. That's the mood board, and it's
   wanted.
5. **Dither is the only ornament.** 1-bit 9×9 pixel icons, glyph dither bars
   (`█▓▒░···`), a glyph heatmap (`· ░ ▒ ▓ █`), and the PR number resolving from
   ordered dither.
6. **Verdicts without colour.** BEAT = solid ink, HIT = ink outline, MISSED =
   dashed and faded. Fill, line and dash carry the meaning.

## 2. Tokens

| Token | Dark (default) | Light | Use |
|---|---|---|---|
| `--paper` | `#1c1724` (plum grey) | `#fcd0af` (FT salmon) | background |
| `--ink` | `#fef8ec` (cream) | `#1e2152` (navy) | text, rules, solid blocks |
| `--accent` | `#fcd0af` | = ink | bars, heatmap, stat values, active tab, `//NOTE`, PR number |
| `--mid` | ink at 58% | ink at 62% | quiet labels, secondary values |
| `--rule` | ink at 22% | ink at 28% | dotted rules (`--hair`), empty tracks |
| `--grain` | 0 | 0.55 | paper-grain overlay (light only) |
| `--dim` / `--behind` | black | navy | sheet backdrop / behind a scaled-back app |

Theme lives on `<html data-theme="dark|light|system">`; `system` follows
`prefers-color-scheme`. The choice is stored in meta (`theme`), applied by
`useTheme()` / `initTheme()`, mirrored to localStorage so `index.html` sets it
before first paint, and `<meta name="theme-color">` tracks the paper colour.

**Destructive actions** use ink with a dashed outline and explicit wording
("Delete this set?"), never red.

The LUME token aliases (`--bg`, `--text-mid`, `--verdict-*`, `--tier-1..5`…) were
deleted on 2026-11-21; only the tokens above exist.

## 3. Type, spacing and lines

Updated 2026-11-22 (spec: `docs/superpowers/specs/2026-11-22-design-system-design.md`).
Every text style is one of the 16 roles below, and nothing else. `tokens.css`
holds each role as a pair, `--text-<role>` (the `font` shorthand) and
`--track-<role>` (letter spacing). `type.css` turns each into a `.t-<role>`
class for JSX. Caps roles also need `text-transform: uppercase`. The `#/kit`
gallery renders every role from `ui/kit/typeRoles.ts`.

**Fonts**, all bundled for offline use:

- `@fontsource-variable/schibsted-grotesk`
- `@fontsource/space-mono` 400/700
- **GymBro Glyph**, our own 4-glyph font for `░ ▒ ▓ █`. Space Mono has none
  of them, and before this the glyphs fell back to the phone's font.
  - It is generated by `tools/dither/build-glyph-font.py`, with the same
    Bayer 4×4 dither as the shadows.
  - Each glyph is one Space Mono character wide, so `1ch` grids line up.
  - `unicode-range` limits it to those 4 code points.

### Space Mono: the spec-sheet voice

| Role | Spec | Job |
|---|---|---|
| `label` | 400 · 11px/1.25 · caps +0.04em | spec labels, legends, day initials, `//NOTE` lines |
| `stamp` | 700 · 11px/1 · caps +0.1em | verdicts, level chips, ready mark |

| `button` | 700 · 13px/1 · caps +0.08em | the primary ink button (outline buttons use `label`) |
| `micro` | 400 · 10px/1.2 · caps +0.04em | chart ticks, tab captions, small units |

**Rules**

- Roles have no weight or case variants. A bold 17px line is `value`. An
  uppercase mono line is `label`.
- The one exception is emphasis on top of a role: a bold number in a
  sentence, the on-state of a segment, a section title, the inverted lockup
  cell. It uses `font-weight: var(--font-strong)` (700), the only weight the
  check accepts besides a role. A role block can't also set `font-family`.
- Glyph sizes come from `--text-glyph` (14px/1, bars and trends) and
  `--text-glyph-sm` (11px/1.25, glyph heatmap).
- Use tabular figures only where columns align (`.tnum`, inputs, stats).
  Schibsted's `tnum` also widens `. , :`, so it is never set globally.

### Spacing: 4px grid

| Token | px | Job |
|---|---|---|
| `--space-half` | 2 | the smallest nudge: a sub-line gap, a field inset, a dither offset (one pixel cell) |
| `--space-1` | 4 | icon to label, tight pairs |
| `--space-2` | 8 | inside a row |
| `--space-3` | 12 | between rows |
| `--space-4` | 16 | inside a section |
| `--space-6` / `--gutter` | 24 | screen sides |
| `--section` | 28 | between sections |
| `--space-8` | 32 | big breaks |
| `--space-12` | 48 | touch target |
| `--space-16` | 64 | page bottom clearance |

- Indents that line text up with a column are exact sums of tokens, such as
  `calc(var(--space-8) + var(--space-3))` for 44px.
- Fixed sizes (widths, heights, heatmap cells) are geometry, not spacing.
- Centring uses the `translate` property, never negative half-width margins.

### Lines: two weights

| Token | Spec | Job |
|---|---|---|
| `--hair` | 1px dotted `--rule` | dividers between rows, empty tracks, quiet outlines |
| `--rule-w` | 1.5px solid, ink or accent | section heads, outlines that carry meaning (HIT, active tab, inputs, Lockup) |

- Focus rings and a focused field's underline are `calc(var(--rule-w) * 2)`,
  because Chrome draws a 1.5px outline as 1px.
- Rings sit inside a cell with `outline` and a negative `outline-offset`,
  never `box-shadow`.

### The check

`tools/check-styles.mjs` runs at the end of `npm run build`, and as a vitest
test. It fails on any of these outside the token files:

- a raw `font`, `font-size`, `font-weight` or `font-family`, or a raw
  `letter-spacing`
- a caps role without uppercase, or uppercase on a role that isn't a caps role
- a raw padding, margin or gap length
- a border or outline width other than `--hair` or `--rule-w`
- a hex, `rgb()` or `hsl()` colour
- a radius
- a shadow
- the same in TSX inline styles

The escape hatch is a same-line `/* ds-allow: <reason> */` in CSS, or
`// ds-allow: <reason>` in TSX. The reason is required, and the test caps
these at 6. Today there are 5:

- 2 page-edge push shadows
- the runtime `--sheet-hide` padding
- the heatmap month offset
- the trend glyphs' spacing

## 5. Motion (Apple HIG feel, Android-safe)

- **Springs, not curves.** `motion/spring.ts` solves the damped oscillator
  analytically (iOS `response` + `dampingFraction`), seeded with the finger's
  release velocity, so a fling carries into the settle. Presets: push 0.35/1,
  sheet 0.4/1, thumb 0.32/0.78. A wall-clock watchdog finishes any spring whose
  frames stop (backgrounded page).
- **Push / pop.** The new page slides in over the old one, which parallaxes 30%
  and dims; pop is the reverse. Tab switches are instant.
- **Android back.** No custom edge swipe: Android's system gesture owns the
  edges. Every push is a real history entry stamped with its stack index
  (`history.state.gbIdx`); a lower index on popstate means pop, so the system
  back gesture/button plays the pop. `go(path, {replace, transition})`,
  `back(fallback)`. Plain `<a href="#/…">` links work too. Scroll is saved per
  entry and restored on pop. The document never scrolls; each page is its own
  scroller inside a fixed frame.
- **Sheets.** Medium and large detents (or one "fit" stop for short content),
  grabber, drag anywhere except text fields and `[data-no-drag]` controls,
  fling projected with UIScrollView deceleration, rubber-band past the top,
  fling down to dismiss, the app scales back at the large detent. Focus trap,
  Esc, backdrop tap, focus returns to the opener. Closing animates whether the
  parent sets `open={false}` or unmounts the sheet.
- **Press feedback on touch-down** for `.btn` and `[data-press]`, cancelled if
  the finger drifts into a scroll, fading on release.
- **Large titles** collapse into the navbar (with an ink rule) on scroll.
- **Action sheet**: slide a finger across the buttons and release to pick.
- **HUD**: pops in, draws its pixel icon row by row, fades after 1.5 s.
- **PR moment**: the number resolves from coarse Bayer dither to solid type on a
  canvas, with `haptic('pr')`.
- **Haptics**: `haptic('commit')` on set commit, `haptic('pr')` on the PR
  moment; the Settings "Haptics" toggle persists the choice in meta (`haptics`,
  default on) via `useHaptics()` / `initHaptics()`, and `haptic()` respects it.

## 6. Accessibility

- Contrast: ink on paper is about 17:1 (dark) and 10.6:1 (light); accent salmon on
  dark is about 13.5:1. `--mid` is for labels, never the only carrier of a value.
- Touch targets are at least 48px; the primary block is 58px.
- `prefers-reduced-motion`: springs jump to their end, the PR number shows
  solid at once, CSS durations drop to ~0.
- Meaning never rests on colour (there is only one): verdicts use fill, outline
  and dash; bars are `role="meter"`; the heatmap has a text summary.
- Modals trap focus and restore it; the app frame is `inert` behind them.

## 7. Anti-patterns

- A second hue, red for errors, or green for "good".
- Cards, borders around content, drop shadows, rounded corners.
- Body text under 15px; long text in Space Mono (keep mono to labels, stats, notes).
- A raw font, size, spacing length, line width, colour, radius or shadow anywhere outside `tokens.css` / `type.css` / the generated `dither.css`. `tools/check-styles.mjs` fails the build on it.
- A custom left-edge swipe-back (Android owns it), or navigation that bypasses
  history (`location.hash =` from code: use `go`).
- Count-up numbers, confetti, looping motion. The one celebration is the PR moment.
- Tabular figures on running text.

## Dither layer ("Clean", 2026-11-21)

Depth comes from three quiet dither effects and nothing else. The owner rejected glows, vignettes and shadows on numbers as too much.

- **Drop shadow:** a 50% ordered-dither strip just outside the bottom-right of buttons, the header lockup, segmented controls, steppers, BEAT/HIT chips and action sheets. It is 3 px (2 px on small controls) and shrinks to 1 px while pressed. Salmon in dark, navy in light.
- **Section fade:** a 3-row dither fade (50 / 25 / 8%) under section-heading ink lines.
- **Layer edges:** the same fade above the tab bar, and a darker one above sheets.

Generated by `tools/dither/build-css.mjs` into `web/src/styles/dither.css` (inline SVG tiles, 2 px cells, Bayer 4×4). Edit the generator, not the CSS.
